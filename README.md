## Deskripsi

Project ini dibuat sebagai salah satu tugas mata kuliah **Pemrograman Mobile** menggunakan Kotlin. Aplikasi memanfaatkan Google Maps untuk menampilkan peta, lokasi, marker, dan informasi posisi pengguna.

---

## Fitur

- Google Maps
- Marker lokasi
- Informasi lokasi
- Navigasi peta

---

## Teknologi

- Kotlin
- Android Studio
- Material 3
- Jetpack Compose
- Google Maps SDK
